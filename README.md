# LALR1parser
DeRemer-Pennelloアルゴリズムを基に実装したLALR1パーサーです。  

## 目的
このプロジェクトは将来的に自作CPU上で動かす自作コンパイラの作成の為の一環として、アルゴリズムの理解の為に実装したものです。  

## 使用方法
モジュールとして読み込み、LALR1関数に構文定義ファイルのパスと解析したい文字列を渡します。  

## 制約・注意点
- 字句解析が弱い為、実用的な解析は行えません。  
- エラー処理に関して最低限の物しか実装していません。  
- 規則の優先順位は基本的に先に記述された物が優先されます。
